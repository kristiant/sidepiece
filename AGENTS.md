# Sidepiece: Agent Guide

macOS menu bar app that triggers snippets and actions from global hotkeys, mainly the numpad.

## Stack

- Swift and SwiftUI for views, AppKit for the status bar, HUD panel, clipboard and event tap
- Project generated by XcodeGen from `project.yml`. Don't commit `Sidepiece.xcodeproj`

## Build and test

- `scripts/build_and_run.sh` generates the project, builds to `./build/Debug` and launches
- `xcodebuild test -project Sidepiece.xcodeproj -scheme Sidepiece -destination 'platform=macOS'`

## Accessibility

- `GlobalHotkeyMonitor` uses `CGEvent.tapCreate`, which needs Accessibility access
- macOS drops the grant when the binary path or signature changes, so builds go to a fixed path
- `HotkeyManager` polls every 2s and starts the monitor once access is granted
- `scripts/reset_permissions.sh` clears a stale grant

## HUD

- `NSPanel` at `.mainMenu` level, bottom-right of the screen
- Idles as a small dot. The window shrinks to fit it so it doesn't block clicks on apps behind
- Peek panel lists what each key does. While open, the number row and Esc also work

## Folders

- Inside a folder, keys 7 8 9 / 4 5 6 / 1 2 3 / 0 map to its items in order
- `Clear` goes up one level
- Auto-exit to root after 5s idle, toggled in Settings

## Guidelines

- Australian spelling in UI text and docs
- Colours come from the `Color.sp*` tokens in `DesignTokens.swift`
